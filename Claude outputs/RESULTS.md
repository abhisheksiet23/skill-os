# skillmesh all-skills study: unmasked results (2026-11-16)
Design: 22 skills (app-qa covered separately), 1 fictional case each, no-skill vs skill, 1 run per side, blinded graders in 5 batches, my own answer keys. Nothing applied to skill-os.

## Tally
Skill wins 15, base wins 6, tie 1. Mean scores (0-5): skill 4.64 correctness / 4.77 honesty / 4.50 usefulness; base 4.18 / 4.27 / 3.95.
Caution: n=1 per case, same model, my keys, many wins at low confidence, blinding imperfect (style may leak).

## Per skill (winner, confidence, why)
- app-analyze: SKILL (med). Kept conflicting emails as open gap; base defaulted to $200 and invented approval chain (tagged unconfirmed).
- app-design: TIE (low).
- app-prototype: SKILL (med). Blocked used-item state; fee math in cents; reported headless Chrome check.
- app-deliver: SKILL (low-med). Operator steps with stop conditions; explicit "not authorized".
- app-backend: SKILL (low-med). Real concurrency tests; both 12/12 hidden tests.
- app-frontend: BASE (low, near tie). Skill coerced bad qty silently; both 8/8.
- code-navigation: SKILL (low-med). Same 5/5 sites; skill noted finalize() ripple.
- project-context: SKILL (high). Scored assessment with N/A; base gave none.
- project-manage: BASE (low-med). Base led with reassign-T4 decision; same dates.
- business-challenge: SKILL (low-med). Decisive test, reversal criteria.
- business-model: SKILL (low). All numbers equal; skill hedged cause of 11x.
- business-pricing: SKILL (med). Base mean $9.67 slip; skill concrete ladder test with thresholds.
- business-validate: SKILL (med). Thresholds with inconclusive band.
- market-research: BASE (low). Base had more sourced competitors; skill clearer evidence grading; neither built value curve.
- venture-investigate: SKILL (low-med). Claims labelled contradicted/assumed/unknown; fixed test threshold.
- naming-architect: SKILL (med). Ran domain lookups (16-17 taken); base none. Neither verified its shortlist names.
- website: SKILL (med). Promise/proof/fit/objection/action table.
- website-build: BASE (low). Skill added features outside direction (JS submit) though verified better.
- website-create: SKILL (med-high). Base showed $350 against "unpublished"; overreaching copy; no not-rendered statement.
- website-deliver: SKILL (low). "Verified live: nothing" block; signal-by-signal measurement.
- website-discover: SKILL (med). Health-claim compliance flagged; cited context honestly.
- website-review: BASE (low, near tie). Both found all 7 planted defects; base ordered conversion-breaking issues first and added a short fix list; skill alone noticed form fields lack name attributes.

## Patterns
- Objective checks equal (hidden tests, flags, code-nav sites, model numbers).
- Skill advantage is process rigor: decision-ready tests with thresholds, labelled assumptions, honest "not verified" blocks, scored assessments.
- Base advantages: occasionally more sourced competitors, scope discipline (website-build), decision-led recommendation (project-manage).
