# Choose the visual system

Use this reference when the project has no existing design system or tokens, or for a new visual direction or a material visual change. An existing identity and design system win. Extend them instead.

Choose roles and reasons, not default values. Derive them from brand, audience, task and density. Record the chosen tokens, their reasons and the icon mapping once, in design artifacts.

Spend visual weight where attention or a decision is needed. Surfaces for sustained use, such as long reading, stay calm: quiet chrome, comfortable type, one accent.

A default is not a decision. A system font stack, one blue accent and a uniform radius are acceptable only when chosen for the audience and brand, with the reason noted.

| Element | Decide | Check in the rendered output |
| --- | --- | --- |
| Type | Font roles (interface, data, display if any), scale steps, weights, line height, measure. Reason from audience, density and language | Smallest size stays legible. Numerals and long values align. A fallback font exists |
| Scale and spacing | One spacing scale, touch target size, density | Dense results at narrow width still scan |
| Color | Roles (surface, text, accent, each status, focus) in a small palette | Text and control contrast. Status never by color alone. Dark mode only when in scope |
| Shape | Radius and border language per surface role, elevation | Nested radii agree. Focus ring is visible on every surface |
| Motion | Purpose of each motion | Reduced-motion setting is honored |

## Iconography
Icons carry meaning, so keep them semantic.

- One icon has one meaning, used the same way everywhere.
- Pair an icon with a visible label unless its meaning is universal in this product, such as close or search.
- An icon-only control gets an accessible name and a tooltip.
- For a consequential or ambiguous action, never rely on an icon alone or on color alone.
- Use one set with a consistent style, stroke and size on a grid. Prefer the project's existing set.
- Add no decorative icon that carries no meaning.
- Record the icon-to-meaning mapping with the tokens.
- Check that similar-looking icons do not mean different things, and that each action's icon matches its label.

Checklists and aesthetic scores do not prove quality. Inspect the rendered output.
