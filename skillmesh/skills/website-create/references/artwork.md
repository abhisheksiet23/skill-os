# Choose, produce and integrate website artwork

An image must communicate the intended idea and work in the actual page. Treat factual truth, rights and placement as production inputs, not checks postponed until the image looks attractive.

## Terms
- **Documentary asset:** an image of real people, facilities, projects, products or customer proof.
- **Conceptual asset:** an image that conveys an idea or atmosphere and depicts nothing real about the company.
- **Visual slot:** one place on a page where an image does a defined job.
- **Source artwork:** the original concept file, kept apart from the optimized delivery files.

## Plan visual roles before generating assets
Do this for a new site or material redesign, alongside the narrative.
- Per slot: decide what the visitor should understand and whether the image is documentary or conceptual.
- Record: page and section, source, style, mobile and desktop crop or composition, dimensions, accessibility treatment, rights and provenance, and status.
- Where: keep this in existing project records. Do not create a separate asset bureaucracy.
- Effort: estimate unique artwork, reusable variants, production effort and external cost before expanding the family. Five delivery crops of one image are not five creative concepts.
- Separation: keep source artwork apart from optimized delivery files so later responsive changes do not require recreating the concept.
- Quantity: let communication needs decide it. There is no mandatory image per section, image-to-text ratio or quota of generated artwork.
- Examples: a small service site might use one signature illustration, a few supporting visuals and a handful of genuine proof and team images. A portfolio may need many project photographs. A typographic consultancy may need very few.
- Count: count the actual slots before committing effort.
- Never invent documentary images to reach a visual-density target.

## Choose the production method

| Visual need | Preferred approach |
| --- | --- |
| Actual people, facilities, projects, products or customer proof | Supplied or commissioned authentic assets with usable rights and factual context |
| Brand-specific conceptual illustration, atmosphere, textures or expressive raster artwork | Available image-generation tools or commissioned illustration. Recommend specialist expertise if needed |
| Precise process diagrams, charts, simple geometric graphics, icons or editable vector work | SVG, HTML/CSS or established vector and icon tools, with real data and accessible labels |
| Product interface demonstration | Real screenshots or a truthful, labeled prototype. Preserve legible interface text |
| Supporting contextual photography | Licensed stock when it genuinely fits, without implying it depicts the company or its work |

Rules:
- Real text: do not use generated raster text for headings, calls to action, logos, precise charts or interfaces that need accuracy and accessibility. Keep them as real text, vector or UI.
- Brand assets: preserve established brand assets. Do not regenerate them.
- Licensing: check licensing and publication suitability. Do not promise legal certainty from an automated assessment.

## Produce a coherent family
Start with one representative asset.
- Art brief: page role, subject or idea, palette, lighting and materials or illustration language, focal point, composition, negative space, and misleading implications to avoid.
- Test: place it beside real copy on mobile and desktop before multiplying it. If crop, contrast or content competition fails, revise the brief or composition first.
- Extend: once the direction works, extend the family using approved references and style consistently where tools support them.
- Scope: produce only the meaningful remaining visuals and necessary variants. Unrelated generation prompts must not decide the site's visual identity.
- Inspect each selected final asset for artifacts, inaccurate details, unintended text, style drift, low resolution and misleading representations.
- Inspect each asset in its rendered placement. Standalone beauty does not establish useful meaning, acceptable download cost or a successful crop.
- Fix failures through composition, responsive variants or a different visual approach. Do not apply overlays everywhere.

Tools and authority:
- When generation is chosen and authorized, select tools and follow their instructions. Image-generation expertise may be recommended.
- Missing tools or authentic materials: state the dependency and use an intentional alternative. Do not silently replace the promised direction with generic placeholders.
- Never purchase paid assets or commission work. If one is required, ask the user to buy it.

## Deliver for mobile first
- Focal points: plan them and the image variants for narrow layouts before wide crops.
- Crops: if cropping cannot preserve the meaning, create a separate composition or use a responsive picture treatment.
- Text: keep text out of bitmap artwork wherever it must stay readable, translatable or accessible.
- Files: use appropriate responsive source sizes and optimized formats with necessary fallbacks. Reserve image dimensions to avoid layout shifts.
- Loading: prioritize the actual above-the-fold (largest contentful paint) image. Lazy-load offscreen images, not the hero.
- Alternatives: give meaningful images useful alternative text. Give decorative images empty alternatives as appropriate.
- Video: avoid autoplay-heavy video as a default shortcut. When motion is justified, use a deliberate poster or static image and a reduced-motion treatment.

## Hand off
- Keep editable and source assets and generation provenance separate from optimized public files.
- Record selected paths and remaining gaps in the existing project plan.
- Check that the public output contains only intended, appropriately licensed assets. Private references and rejected generation attempts are not website deliverables.
