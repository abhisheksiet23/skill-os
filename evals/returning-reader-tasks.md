# Returning-reader implementation evaluation

Use matched, isolated contexts with the same captured source and request. Baseline uses the pre-change frontend/backend skills; candidate uses the revised skills. Keep peer outputs and assessment criteria from performers. Capture actual source changes and commands in ignored `.eval-runs/readability/`; do not refactor the active application's files. Synthetic tests and successful compilation do not establish production integration or owner comprehension.

## Performer request

Refactor the supplied application approve-and-assign workflow for readability for an owner returning to code after six years. Work from a frozen source copy. Preserve permissions, approval cycles, assignee/team eligibility, accumulated team visibility, history, transactions, version conflicts and retry behavior. Keep unrelated workflow changes out. Produce actual code, execute feasible checks, and identify unavailable integration proof. Follow the action from form selection through API handling and persisted approval. Do not claim the owner finds it readable without their feedback.

Capture the frontend component, template and API contracts and the backend ticket service, account service and models from the same source snapshot. Additional dependencies can be read or copied to isolated scratch for compilation. Record source hashes so later edits in the active project cannot be mistaken for the evaluated candidate.

## Assessment after collecting outputs

Check whether a reader can locate the action, understand selected assignee/team values, identify the request/response contract, follow permission and eligibility checks, and explain state/history changes and retry/conflict handling. Look for purposeful boundaries and names, visible template nesting and necessary explanations of mechanisms. Penalize both compressed monoliths and fragmentation into trivial helpers. Check preserved behavior independently of presentation; record observed regressions and unproved guarantees. Compare actual outcomes rather than counting instruction keywords, file counts or lines. Record owner comprehension, external integration, provider tokens and timing as unknown unless measured.
