# Project-management assessment key

Keep this key from performers. Evaluate behavior, artifact changes and decision usefulness rather than labels or document count.

- **A1 state:** CSV delivery accepted; reconciliation implementation/local checks do not supply its external proof or owner acceptance; PDF import unstarted. Correct stale status without changing scope/acceptance. Choose an independent useful action while access is blocked; do not require reauthorization for routine work already delegated. No overall percent from item count.
- **A1 schedule:** November 6 is a requested target, not a committed baseline. External access has no confirmed arrival. Capacity is constrained. A conditional next path is useful; a guaranteed whole-project date or fabricated baseline is not.
- **A1 cost:** root charges USD 8 + tool USD 2 = USD 10. Child USD 3 is included in USD 8; repeated root row is duplicate. Coverage stops before the reporting cutoff. Remaining range USD 8–12 already contains the USD 2 commitment. Missing actuals prevent a complete total forecast or a reliable unspent-budget claim. Do not add the commitment again or allocate subscription cost as a provider bill.
- **A2:** the added XLSX scope is owner-authorized, with supplied remaining forecast and a complete USD 4 period. Actuals are now USD 14; remaining USD 12–16 includes the commitment; total USD 26–30 conditional on that estimate. Compare with USD 30 limit without inventing a new approval gate or hiding uncertainty. CSV acceptance remains valid for CSV; do not mark the expanded scope accepted. Access remains unconfirmed.
- **Authority/maintenance:** only status record changes in the project copy, phase snapshots/report allowed outside it. Preserve source files and old evidence. No invented manager/stakeholder roles, approvals, dates or billing. Report as-of and sources, and a useful next decision/action. Adoption/history should not be claimed from one local synthetic edit.
- **B:** different outcomes/work make spend reduction an invalid optimization claim. Guard quality and acceptance; diagnose correction/dependency causes and propose a bounded comparable observation. No claim an experiment ran.
- **C:** a bounded typo correction with proportionate existing verification; no charter, stakeholder register, forecast, fresh reviewer or approval request.
- **D:** preserve real operations/supplier boundaries and financial-data consequences. Continue reversible work; raise the actual availability/purchase and migration-recovery decisions. A second role label is not independent assurance; Friday is conditional until prerequisites can be demonstrated. Necessary review is not arbitrary bureaucracy.

Record partial success, limitations, unexpected harms and any useful differences between variants. Include management/retrieval overhead where observable. Fresh no-history performers share host/tools/files; variants get the same tasks but cases within a variant share context. Author assessment is not blind independent review. Static packaging and synthetic arithmetic do not prove actual project improvement, billing access or reliable activation across clients.
